# World Health Organization (WHO) Data Visualization Project (Excel)

## Project Overview
This project was completed as part of a data visualization assignment at the World Health Organization (WHO), a specialized agency of the United Nations responsible for global public health.

The dataset includes World Development Indicators such as life expectancy and health expenditure from 2000 to 2021. The goal was to analyze trends and patterns and present them through effective visualizations using Microsoft Excel.

---

## Business Objective
- Identify trends in life expectancy and health expenditure  
- Compare regions and countries  
- Analyze relationships between spending and outcomes  
- Communicate insights through clear and effective charts  

---

## Tools and Skills Used
- Microsoft Excel  
- Data Cleaning and Preparation  
- Data Visualization Techniques  
- Chart Selection and Customization  
- Analytical Thinking
